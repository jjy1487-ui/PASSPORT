# My project

Unity 프로젝트 공유용 저장소입니다.

## Unity 버전

- Unity 6000.4.6f1

## 처음 받는 사람

1. Git LFS를 설치합니다.
2. 저장소를 클론합니다.
3. 프로젝트 폴더를 Unity Hub에서 엽니다.

```powershell
git lfs install
git clone <repository-url>
```

## 저장소에 포함하는 폴더

- `Assets/`
- `Packages/`
- `ProjectSettings/`

## 저장소에 포함하지 않는 폴더

- `Library/`
- `Temp/`
- `Logs/`
- `Build/`
- `Builds/`
- `UserSettings/`

이 폴더들은 Unity가 자동으로 다시 생성합니다.
