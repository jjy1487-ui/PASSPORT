# 여권 주세요 — UI/UX 일관성 규약 (Design System)

> `passport-ui` 에이전트는 **모든 UI 작업에서 이 문서를 따른다.** UI/UX의 핵심은 일관성이다 —
> 같은 기능은 항상 같은 모습·같은 위치·같은 동작을 가진다. 예외를 만들지 않는다.
> 아티스트가 그려온 UI도 이 규약에 맞춰 세팅한다. 규약과 그림이 충돌하면 **이 문서를 기준으로 조정**하고 기록한다.

기준 전제(바뀌면 맨 먼저 여기 수정):
- **플랫폼/해상도**: PC 가로, 기준 해상도 **1920×1080 (16:9)**.
- **CanvasScaler**: `Scale With Screen Size`, Reference 1920×1080, Match = 0.5.
- 단위: 기준 해상도 px. 간격은 **8px 그리드**의 배수(4/8/16/24/32…).

## 1. 버튼 규칙 (가장 중요 — 절대 통일)

| 버튼 | 모양 | 위치 | 색/상태 | 단축키 |
|------|------|------|---------|:---:|
| **닫기** | `X` 아이콘 (텍스트 아님) | 패널 **우상단**, 모서리에서 16px 안쪽 | 중립색, hover 시 강조 | `Esc` |
| **확인/주요(Primary)** | 채워진 버튼 + 텍스트 | 액션 영역 **오른쪽** | Primary 색 | `Enter` |
| **취소/보조(Secondary)** | 외곽선 버튼 + 텍스트 | 확인 **왼쪽** | 중립색 | `Esc` |
| **통과 도장(Approve)** | 도장 아이콘+"통과" | 데스크 하단 **좌측** 고정 | **승인 그린** | `F` (+마우스) |
| **거절 도장(Reject)** | 도장 아이콘+"거절" | 데스크 하단 **우측** 고정 | **거절 레드** | `J` (+마우스) |
| **도구(xray/지문/확대경)** | 아이콘 버튼 | 데스크 **우측 도구바**, 세로 정렬 | 중립, 해금 전 잠금표시 | `1` `2` `3` |

> 확정 단축키: 통과 `F` · 거절 `J` · 도구 `1`/`2`/`3` · 확인 `Enter` · 닫기/취소 `Esc`.
> 통과/거절은 **색만으로 구분하지 않는다**(적록색약 대비) — 위치(좌/우) + 텍스트 + 도장 아이콘 3중 구분.

규칙:
- **확인은 항상 오른쪽, 취소는 항상 왼쪽.** 순서를 뒤집지 않는다.
- **통과=좌, 거절=우**를 게임 전체에서 절대 고정(근육 기억 형성 — 레벨디자인의 숙련감과 직결).
- 닫기 버튼은 **항상 X, 항상 우상단**. "뒤로" 텍스트 버튼으로 대체하지 않는다.
- 모든 버튼은 최소 터치/클릭 영역 **44×44px** 이상.
- 비활성(disabled) 버튼은 **숨기지 말고 흐리게**(상태를 보이게).

| 토큰 | 의미 | 용도 | HEX (다크 데스크 기본) |
|------|------|------|------|
| `Approve/Green` | 통과·정답·긍정 | 통과 도장, 정답 피드백 | `#2E8B57` (강조 `#36A26A`) |
| `Reject/Red` | 거절·오답·위험 | 거절 도장, 오판 경고, 결함 하이라이트 | `#C0392B` (강조 `#E05546`) |
| `Warning/Amber` | 주의·경고 | 경고(-50) 알림, 만료 임박 | `#E0A82E` |
| `Neutral/Gray` | 중립·보조 | 닫기/취소, 비활성 | `#7A828C` |

| `Score/Blue` | 점수(엔딩) | 점수 HUD | `#3B82C4` |

표면/배경(다크 데스크):
| 토큰 | 용도 | HEX |
|------|------|-----|
| `Bg/Desk` | 최하단 배경(책상) | `#1E2228` |
| `Surface/Panel` | 패널·HUD 바 | `#2B313A` |
| `Surface/Raised` | 버튼·카드 | `#39414C` |
| `Document/Paper` | 서류 바탕(밝게 대비) | `#EDE6D6` |
| `Text/OnDark` | 어두운 표면 글자 | `#ECECEC` |
| `Text/OnPaper` | 서류 글자 | `#1A1A1A` |
| `Line/Divider` | 구분선·외곽선 | `#4A525E` |

- **돈과 점수는 색으로도 구분**(공통 규약: 점수≠돈). 같은 색 쓰지 말 것.
- 결함 필드 하이라이트는 항상 `Reject/Red` 계열로 통일.
- 색은 코드에 하드코딩하지 말고 **UITheme(ScriptableObject)** 한 곳에서 정의해 참조(아래 6장).

## 3. 타이포그래피

- **UI 폰트(추천): Pretendard** — 무료(OFL), 한글/영문/숫자 균형 좋고 UI에 최적. TMP 폰트 에셋으로 변환해 사용.
  - 대안: Noto Sans KR(무난), 본고딕.
- **서류 폰트(추천): 고정폭/타자기 톤** — 여권·증명서 느낌. 영문 서류는 모노스페이스(예: Roboto Mono), 한글 서류는 본명조/Noto Serif KR.
  - 이유: UI(산세리프)와 서류(타자기/명조)를 **시각적으로 분리**하면 "서류를 검토한다"는 맥락이 살아난다.
- 위계(기준 px): 화면 타이틀 **40**, 패널 제목 **28**, 본문 **20**, 보조/캡션 **16**.
- 한 화면에 3단계 이상 크기 혼용 금지. 강조는 **굵기/색**으로, 크기 난발 금지.
- 폰트 파일은 사용자/아티스트가 최종 확정(라이선스 확인). 확정 전에는 Pretendard로 작업.

## 4. 패널/모달 규칙

모든 패널은 동일 구조를 가진다:
```
[Panel]
 ├ Backdrop      (반투명 딤 0.6, 클릭 시 닫힘 — 단 결과/엔딩 등 강제 패널은 제외)
 ├ Frame
 │   ├ TitleBar  (제목 좌측 + 닫기 X 우상단)
 │   ├ Body      (내용)
 │   └ ActionBar (우측 Primary / 좌측 Secondary)
```
- 열기/닫기 트랜지션 **통일**(예: 0.15s 페이드+살짝 스케일). 패널마다 다른 연출 금지.
- 한 번에 **모달 1개**만. 모달 위 모달 지양.
- 패널은 화면 중앙 정렬, 최대 폭 제한(가독성).

## 5. 레이아웃 & 앵커

- **앵커를 명시적으로** 설정(중앙/모서리). 화면 비율이 바뀌어도 안 깨지게.
- HUD는 상단 바에 고정: 좌측 = 일자/슬롯, 중앙 = 규칙/뉴스 알림, 우측 = 점수·돈.
- 검사 데스크는 중앙 작업영역, 도구바는 우측, 도장은 하단. **이 배치를 전 일자에서 고정.**
- 안전 여백: 화면 가장자리 최소 24px.

## 6. 코드로 일관성 강제 (문서로만 두지 않는다)

말로 된 규칙은 어겨진다. 코드 구조로 못박는다:
- **`UITheme` ScriptableObject**: 색 토큰·간격·트랜지션 시간·폰트를 한 곳에. 모든 UI가 여기서 읽음(색 하드코딩 금지).
- **`UIPanelBase` (추상 MonoBehaviour)**: 모든 패널이 상속. Open/Close 트랜지션, 닫기 X 처리, Esc 처리, Backdrop을 공통 제공 → 패널마다 재구현 금지.
- **`StampButton` 공통 컴포넌트**: 통과/거절 도장 동작·색·단축키를 한 곳에.
- 버튼 프리팹은 **공용 프리팹**(`Btn_Primary`, `Btn_Secondary`, `Btn_IconClose`, `Btn_Stamp`)을 재사용. 매번 새로 만들지 않는다.

## 7. 아티스트 핸드오프 규칙 (그림 받아서 세팅하는 기준)

아티스트 에셋을 받으면:
- **네이밍**: `ui_<용도>_<상태>` 예) `ui_btn_close`, `ui_btn_stamp_approve`, `ui_panel_frame`. 상태는 `_normal/_hover/_pressed/_disabled`.
- **9-slice**: 늘어나는 프레임/버튼 배경은 9-slice 가능하게 여백 포함 요청. Import에서 Border 설정.
- **해상도**: @1x = 1920 기준. 스프라이트는 여유 배율(2x) 권장.
- **포맷**: 투명 PNG, 픽셀 정렬. 텍스트는 이미지에 굽지 말 것(TMP로).
- 받은 그림이 규약(위치/색/크기)과 다르면 → **규약 우선**으로 배치하고, 아티스트에 어긋난 점을 피드백.

## 8. 합의 항목 (기본값 채움 — 변경 시 여기서)

## 10. 데이터 테이블 → 필요한 UI 요소 (무엇을 만들어야 하는가)

> 각 테이블이 요구하는 화면/위젯. `passport-ui`는 이 목록을 빠짐없이 구현한다.

| 데이터 | 필요한 UI 요소 | 비고 |
|--------|---------------|------|
| `customer` | **방문객 영역**: 초상(sprite_ref)·이름(name_kr) | 화면 좌측 상단(인물) |
| `passport`/`visa`/`pcr_test`/`employment_cert` | **서류 카드**(서류별): 필드 라벨+값, 드래그·줌, 결함 하이라이트 | 키-값(`DocumentInstance.fields`)을 meta 라벨로 표시 |
| `document_requirement` | **오늘 요구 서류 체크리스트** 패널 | 제출/누락 표시 |
| `rule_book` | **규정 브리핑**(하루 시작 모달) + 인게임 **규정집 열람** 버튼 | related_field 강조 |
| `news` | **뉴스 팝업**(하루 시작): 제목·본문·아이콘 | day별 |
| `dialogue_case`/`dialogue_line` | **대사창**: 화자(캐릭터/심사관)·텍스트, **라운드 진행 표시**, 재심사 루프(최대 3회) 안내 | 공통규약 4-A. 통과/거절 후 분기 대사 자동 진행 |
| `xray` | **엑스레이 뷰**: 결과(적발)·숨긴 물품·위치 시각화 | 도구바 도구 |
| `fingerprint` | **지문 조회 패널**: 일치 상태·수배 정보 | 도구바 도구 |
| `shop` | **상점 화면**: 아이템 카드(이름·분류·가격·해금일·효과), 구매 버튼, 잠금 표시 | 돈으로 구매 |
| `reward`/`score_model` | **하루 종료 정산 화면**: 일급·적발·퍼펙트·경고 내역, 점수·돈 합계 | 점수≠돈 분리 표시 |
| `ending` | **엔딩 화면**: 점수구간별 엔딩명·이미지·텍스트 | score_min~max 매핑 |
| (진행) `day_schedule` | **상단 HUD**: 현재 일자/슬롯(N/7) 진행바 | 항상 표시 |

핵심 화면 묶음: ① 하루 시작(뉴스+규정 브리핑) → ② 검사 데스크(방문객·서류·도구·도장·**대사창/재심사 루프**) → ③ 하루 종료(정산) → ④ 상점 → (회차 끝) ⑤ 엔딩.

### 10-A. 재심사 루프 UI (대화 3회)
- 거절 판정 후 **즉시 끝내지 않는다**: 손님 항의 대사를 대사창에 출력하고 **재심사 상태**로 돌아간다(서류 다시 검토 가능).
- 현재 라운드를 표시(예: 작은 "재심사 1/3" 인디케이터). 3회째엔 강제 종료 대사 후 정산.
- 이 동작의 **판정·분기·카운트는 gameplay가 결정**, UI는 gameplay 이벤트(대사 시퀀스/라운드)만 받아 출력한다.

## 부록 A. UITheme 기본값 (ScriptableObject에 그대로 입력)

```
[Semantic]
approve        = #2E8B57   approveStrong = #36A26A
reject         = #C0392B   rejectStrong  = #E05546
warning        = #E0A82E
neutral        = #7A828C
money          = #D4A017
score          = #3B82C4

[Surface]
bgDesk         = #1E2228
surfacePanel   = #2B313A
surfaceRaised  = #39414C
documentPaper  = #EDE6D6
lineDivider    = #4A525E

[Text]
textOnDark     = #ECECEC
textOnPaper    = #1A1A1A

[Type]  (px @1920x1080)
title=40  panelTitle=28  body=20  caption=16
fontUI=Pretendard   fontDocument=Mono/Serif

[Layout]
grid=8   screenMargin=24   minHit=44   panelMaxWidth=960

[Transition]
panelFade=0.15s   panelScaleFrom=0.96
```

> 위 값은 **다크 데스크 기본 프리셋**이다. 라이트 페이퍼로 바꿀 경우 Surface/Text만 교체하고 Semantic은 유지한다.

## 9. 완료 기준 (UI DoD에 추가)

- [ ] 닫기 = X·우상단, 확인=우/취소=좌, 통과=좌/거절=우 **전 화면 동일**
- [ ] 색은 UITheme에서만 참조(하드코딩 0)
- [ ] 모든 패널이 `UIPanelBase` 상속(트랜지션·닫기 통일)
- [ ] 공용 버튼 프리팹 재사용(중복 구현 0)
