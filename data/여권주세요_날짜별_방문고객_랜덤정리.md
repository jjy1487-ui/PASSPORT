# 여권 주세요 — 날짜별 방문 고객 정리

> 표의 목적: 14일 동안 어떤 유형의 고객이 어떤 순서로 등장하는지 정리한다.  
> `랜덤◆` 손님은 통과/거절이 미리 고정되지 않고, 등장 시 손님 단위 확률로 정상/비정상이 결정된다.

---

## 표기 해석

| 표기 | 뜻 | 해석 방법 |
|---|---|---|
| `유형·통과` | 고정 통과 손님 | 항상 정상 케이스. 통과가 정답 |
| `유형·거절` | 고정 거절 손님 | 항상 비정상 케이스. 거절이 정답 |
| `유형·랜덤◆` | 확률 기반 랜덤 손님 | 손님 단위 `normal_chance`로 정상/비정상 결정 |
| `◆` | 랜덤 판정 표시 | 정상 결과면 통과, 비정상 결과면 거절 |
| `★` | 특수 캐릭터 | 특정 날짜에 한 번 등장하는 이벤트성 손님 |
| `전염병정상` | 전염병 검사 정상 | PCR 검사 정상. 통과가 정답 |
| `전염병비정상` | 전염병 검사 비정상 | PCR 검사 문제 있음. 거절이 정답 |

### 랜덤◆ 해석

`랜덤◆`은 고객이 랜덤으로 등장한다는 뜻이 아니다.  
**고객은 해당 날짜/슬롯에 고정 등장하고, 정상/비정상 여부만 확률로 결정된다.**

예시:

| 표기 | 정상 확률 | 결과 |
|---|---:|---|
| `진상·랜덤◆` | 0.75 | 정상 75% → 통과 / 비정상 25% → 거절 |
| `성형·랜덤◆` | 0.70 | 정상 70% → 통과 / 비정상 30% → 거절 |
| `범죄자·랜덤◆` | 0.30 | 정상 30% → 통과 / 비정상 70% → 거절 |
| `테러범·랜덤◆` | 0.25 | 정상 25% → 통과 / 비정상 75% → 거절 |

## 읽는 방법

1. 먼저 `일차`를 확인한다.
2. 그날 필요한 `요구 서류`를 확인한다.
3. `방1`부터 `방7`까지 순서대로 고객을 등장시킨다.
4. `통과`/`거절`이 붙은 고객은 고정 판정이다.
5. `랜덤◆` 고객은 손님 단위 정상 확률로 정상/비정상을 먼저 결정한다.
6. 정상 결과면 통과가 정답이고, 비정상 결과면 거절이 정답이다.

---

## 주의사항

- `랜덤◆`은 서류별 확률이 아니라 **손님 단위 확률**이다.
- 한 손님에게 확률 판정은 한 번만 적용한다.
- 비정상으로 결정되면 미리 정한 결함 서류 1개만 비정상으로 만든다.
- 나머지 서류는 정상으로 둔다.
